# 🩺 Expert System for Medical Diagnosis

This project is a **rule-based Expert System** developed in **Python** that predicts possible diseases based on user-selected symptoms and provides precautionary measures. It demonstrates the application of **Knowledge Engineering and Intelligent Systems (KEIS)** principles in healthcare, using a structured knowledge base and forward chaining inference.

---

## 📌 Features
- Rule-based inference engine (forward chaining)  
- **Tkinter GUI** for interactive diagnosis  
- Searchable and scrollable symptom list with checkboxes  
- Real-time diagnosis with **confidence scores**  
- Precautionary measures displayed for each predicted disease  
- Transparent and explainable reasoning (not a black-box model)  

---

## 🛠️ Tech Stack
- **Python 3.x**  
- **Tkinter** → Graphical User Interface  
- **Pandas** → Data preprocessing and management  
- **CSV datasets** → Knowledge base (Diseases, Symptoms, Precautions)
